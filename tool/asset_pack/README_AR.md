# ELEC LAB — حزمة أصول 3D وتعليمات اللوحة

تضم الحزمة 30 ملف GLB منفصلاً، كتالوج الأجهزة، بيانات أولية لنقاط التوصيل، صورة مرجعية لمستوى الواقعية المطلوب، وتعليمات دمج لتطبيق Flutter.

## تنبيه جودة مهم
ملفات GLB الحالية نماذج ثلاثية الأبعاد أولية مولدة برمجياً وليست نسخاً فوتوغرافية مطابقة لأجهزة المصانع أو ملفات CAD معتمدة. الصورة داخل `reference/` مرجع بصري فقط وليست مجموعة مجسمات 3D. للوصول إلى واقعية صناعية قريبة من صور المنتجات الحقيقية، يجب استبدال النماذج الأولية بأصول GLB/CAD مرخصة عالية الجودة أو إعادة نمذجتها يدوياً. لا تستخدم نقاط التوصيل الأولية للحساب الكهربائي قبل معايرتها واختبارها.

## المحتويات
- `models/*.glb` — نماذج 3D أولية منفصلة.
- `metadata/components.json` — تعريفات الأجهزة ونقاط توصيل أولية.
- `docs/BOARD_AND_INTEGRATION_SPEC.md` — مواصفات لوحة ثابتة مناسبة لشاشة الهاتف.
- `docs/AGENT_PROMPT_AR.txt` — تعليمات عربية مفصلة للوكيل.
- `reference/realistic_component_style_reference.png` — مرجع بصري لأسلوب الأجهزة الواقعية.
