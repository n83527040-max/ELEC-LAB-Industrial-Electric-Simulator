اقرأ الملفات كاملة قبل البدء، وافحص حالة المستودع الحالي، ثم نفّذ التطبيق فعلياً باستعمال Flutter وفق المواصفات. لا تكتفِ بإنشاء واجهات شكلية أو خطة؛ المطلوب لوحة عمل تفاعلية، أجهزة ذات نقاط توصيل حقيقية داخل النموذج، أسلاك قابلة للتعديل، تخزين للمشاريع، ومحرك محاكاة له قواعد واختبارات واضحة.

حافظ على سهولة الاستخدام وقلة الأزرار، وعلى التصميم العربي RTL مع المصطلحات الفرنسية، والوضع الداكن والفاتح، والعمل دون إنترنت. استخدم الصور كمرجع بصري وليس كبديل عن الواجهات أو مجسمات 3D التفاعلية.

بعد التنفيذ:
1. شغّل formatter وanalyzer وجميع الاختبارات المناسبة وأصلح الأخطاء.
2. اختبر وظائف التوصيل والحفظ والمحاكاة والحالات غير الصحيحة.
3. نفّذ بناء Release للتطبيق.
4. أنشئ APK قابل للتثبيت، ثم أرفقه لي كملف/Artifact قابل للتنزيل مع رابط مباشر.
5. أعطني تقريراً مختصراً بنتائج الاختبارات والبناء، وحجم APK، والميزات المكتملة فعلياً وأي قيود باقية.

لا تدّعِ اكتمال أي ميزة لم تُنفّذ أو لم تُختبر، ولا ترسل لي مجرد كود غير مبني أو صورة واجهة. إذا تعذر بناء APK في البيئة الحالية، جهّز CI موثقاً لبنائه، واشرح بوضوح ما الذي يمنع توفيره مباشرة.

ابدأ الآن بالعمل داخل المستودع الحالي، واستعمل كل المعلومات الواردة في هذه الحزمة.
