# خطة التنفيذ — ELEC LAB

## المرحلة الحالية (0.1.0)

1. **النواة والبيانات**: مشروع بنسخة schema، مكونات وأطراف مستقلة، أسلاك ومسارات وطبقات، وتحقق صارم عند الاستيراد.
2. **المحرك الكهربائي**: Modified Nodal Analysis بأعداد مركبة، حل DC وAC جيبي متوازن، حالات الكونتاكتور والتعشيق، الحماية والأعطال والقياسات.
3. **المحرر**: لوحة Pan/Zoom وSnap، تحريك/تدوير/نسخ/حذف، توصيل طرف بطرف، تعديل السلك، طبقات، Undo/Redo وحفظ تلقائي.
4. **3D**: meshes إجرائية حقيقية (رؤوس وأوجه وليست صوراً) مع إسقاط منظوري ودوران وتكبير، ومحطات مشتقة من نفس تعريفات المحرر.
5. **التخزين والتصدير**: ملفات JSON محلية ذرّية، مشاريع قابلة للنسخ والاستيراد والمشاركة، نسخة احتياطية، PNG وPDF.
6. **التجربة**: RTL، داكن/فاتح، مكتبة قابلة للبحث، تحديات محلية وتشخيص بلا إنترنت.
7. **التحقق**: اختبارات وحدات وواجهة، analyzer، وبناء Release APK عبر GitHub Actions ورفعه كـ Artifact.

## حدود معلنة للإصدار الأول

- المحلل يحسب DC وAC جيبياً خطياً في مجال الأعداد المركبة؛ لا يحسب العابرات الكهرومغناطيسية أو harmonics أو قصراً واقعياً بمرور الزمن.
- المحرك ثلاثي الطور يستخدم نموذج معاوقة مكافئة متوازنة (مشط واي)، وليس نموذج عزم/انزلاق ميكانيكياً دقيقاً.
- المحول والـVFD وPLC لا يظهران كمكونات قابلة للمحاكاة قبل توفر نموذج صحيح لهما.
- اقتراح مقطع الموصل تعليمي فقط ولا يمثل مطابقة لمعيار كهربائي.
- المجسمات meshes أصلية مبسطة وليست نماذج CAD photorealistic لمصنّع معين.

التفاصيل والمعادلات في `docs/SIMULATION.md`، وصيغة الحفظ في `docs/PROJECT_FORMAT.md`.
