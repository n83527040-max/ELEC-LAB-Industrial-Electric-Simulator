# تخزين وصيغة مشروع ELEC LAB

## التخزين المحلي

يحفظ التطبيق كل مشروع في ملف مستقل داخل مجلد التطبيق الخاص على Android:

`<application documents>/projects/<project id>.eleclab.json`

لا يحتاج إلى حساب أو شبكة أو قاعدة بيانات خارجية. تتم الكتابة إلى ملف مؤقت مع `flush` ثم `rename` ذري. قبل الاستبدال تُحفظ الجيل السابق في `.bak`، ويمكن تحميله إذا تلف الملف الأساسي.

المعرّف يقبل فقط `[A-Za-z0-9_-]{1,100}` لمنع path traversal. اسم المشروع العربي منفصل عن معرّف الملف.

## Schema version 2

الحقول الأساسية:

- `schemaVersion`: حالياً 2.
- `id`, `name`, `description`, `createdAt`, `updatedAt`.
- `board`: العرض والارتفاع.
- `layers`: المعرّف والاسم واللون والظهور والقفل.
- `components`: النوع، المرجع، الموضع، الطبقة، الدوران `0..3`، الحجم `0.6..1.8`، وخصائص scalar.
- `wires`: مرجعا الطرفين، الطبقة، اللون، المقطع، نوع الموصل، تصنيف العزل، نمط المسار ونقاط الانحناء.
- `simulationSettings`: إعدادات قابلة للترقية.
- `lastSimulation`: ملخص نتائج آخر تجربة، وليس مصدراً لحساب نتائج جديدة.

تعريفات الأطراف نفسها ثابتة في `ComponentCatalog` ولا تُنسخ في كل مشروع؛ المرجع المحفوظ هو `componentId + terminalId`. بهذا تتطابق اللوحة والمجسم والمحرك.

الإصدار 1 يُرقّى تلقائياً بإضافة الطبقات والإعدادات الافتراضية. الإصدارات الأحدث غير المعروفة تُرفض بدل قراءتها بشكل خاطئ.

## مشاركة ملف مشروع

ملف المشاركة JSON envelope:

```json
{
  "format": "elec-lab-project",
  "checksum": "SHA-256 of canonical project JSON payload",
  "project": { "schemaVersion": 2 }
}
```

يتحقق الاستيراد من SHA-256 ومن schema وكل المراجع والتكرارات. إذا كان المعرّف موجوداً، ينشئ التطبيق معرّفاً جديداً بدل الكتابة فوق المشروع المحلي.

## النسخة الاحتياطية

النسخة بصيغة `elec-lab-backup`، الإصدار 1، وتحتوي كل وثائق المشاريع. يتم التحقق من كل مشروع قبل الاستعادة. الاستعادة تستبدل المشاريع ذات المعرّف نفسه بعد تأكيد المستخدم.

## الحفظ التلقائي

كل تعديل مهم يعيد جدولة حفظ بعد 450ms؛ السحب المستمر عملية undo واحدة. الرجوع من المحرر والانتقال إلى الخلفية يستدعيان `flush`. آخر نتيجة محاكاة تحفظ عند إيقاف التجربة، ولا تُستخدم بدلاً من تشغيل المحرك.
